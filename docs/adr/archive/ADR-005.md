# ADR-005: Frontend Cinemático SPA (Vite + React + Tailwind), Design System OLED-Safe e Experiência de Streaming

## 1. Contexto & Diagnóstico

Após a consolidação dos provedores de descoberta com fallback resiliente (ADR-002, ADR-003) e da camada relacional com SQLModel no FastAPI (ADR-004), o TV Pirata alcançou maturidade completa no backend (22 testes aprovados).
Contudo, o repositório permanecia sem interface gráfica de usuário, operando apenas via endpoints REST brutos e documentação Swagger.

Para cumprir a missão fundamental do TV Pirata — ser o *"Netflix Pessoal para Descoberta, Controle e Obtenção de Séries"* em ambiente de homelab —, realizou-se um processo estruturado de descoberta combinando o **Context Acquisition Protocol (CAP)**, o motor heurístico de **UI/UX Pro Max & UX Researcher** e a exploração dialética do **Garimpo**.

Todas as 10 recomendações canônicas do Garimpo foram ratificadas para execução:
1. SPA moderna compilada com Vite, TypeScript e Tailwind CSS.
2. Ação híbrida de 1 clique para obtenção de torrents (cópia com toast + gatilho do protocolo `magnet:?`).
3. Arquétipo estético OLED-Safe Deep Slate (`#090a0f`, `#131722`, `#d81f26`).
4. Toggle otimista instantâneo para marcação de episódios e temporadas assistidas.
5. Navbar cinemática translúcida flutuante estilo streaming premium.
6. Responsividade híbrida Mobile-First (375px) a Desktop/TV (1440px+), touch targets $\ge 44\text{px}$ e suporte a teclado/D-Pad.
7. Modal/Drawer de detalhes em camada hero sobreposta com tabs de temporadas.
8. Lazy loading nativo com skeleton screens e fallback SVG para pôsteres.
9. Interface visual com chips interativos para Coleções Inteligentes e Tags.
10. Rastreamento e exibição de badges de disponibilidade de arquivos no servidor SMB local.

## 2. Decisões & Decision Ledger

- **DEC-019 (Frontend Architecture: Vite + React + TypeScript + Tailwind CSS):** Implementação de SPA localizada em `src/frontend/`, com build estático gerado para `src/backend/static/dist`, servido nativamente pelo FastAPI via `FileResponse` em `/` e static assets em `/assets`.
- **DEC-020 (Design System Cinemático OLED-Safe & Tokens WCAG 2.1 AAA):** Paleta Dark Mode com fundo ardósia profunda (`#090a0f`), superfícies de elevação (`#131722`, `#1e293b`), destaque rubro cinemático (`#d81f26`), escala modular de tipografia com `clamp()`, grid de 8pt e áreas de toque mínimas de $44 \times 44\text{px}$.
- **DEC-021 (Navbar Cinemática Flutuante & Navegação Responsiva Híbrida):** Header translúcido com `backdrop-filter: blur(16px)`, navegação por abas (*Descobrir*, *Minha Biblioteca*, *Coleções*), campo de busca debounced conectado a `/api/discovery/search`, e suporte a navegação por teclado (D-Pad para Smart TV / TV Box).
- **DEC-022 (Dashboard de Streaming: Hero Banner & Carrosséis com Lazy Loading):** Banner Hero rotativo com backdrop em alta resolução, carrosséis de pôsteres com scroll-snap suave (`/api/discovery/trending`, Em Andamento, Minha Lista) e skeleton screens para carregamento progressivo.
- **DEC-023 (Drawer/Modal Cinemático com Checklist Otimista de Episódios):** Modal hero com backdrop em alta definição, seletor de temporadas, barra de progresso visual, badge de mídia local SMB (`LocalMediaRecord.is_available`), e alternância otimista imediata de status assistido (`/api/watches/episodes/{id}/toggle` e `watch-all`).
- **DEC-024 (Modal Inteligente de Magnets com Ação Híbrida de 1 Clique):** Agrupamento de releases da EZTV (`/api/torrents/shows/{imdb_id}`) por resolução (4K, 1080p, 720p, SD) ordenadas por seeds, cópia de magnet para clipboard com toast de 3s e gatilho de link `magnet:?`.
- **DEC-025 (Filtros Visuais de Coleções Inteligentes & Gestão de Tags):** Interface interativa de chips coloridos para tags e criação visual de coleções dinâmicas compilando critérios JSON para `/api/collections/smart`.

## 3. Alternativas Consideradas & Trade-offs

- **Alternativa A (Vanilla JS sem build pipeline):** Rejeitada. Embora elimine a etapa de build, o gerenciamento de estado complexo (carrosséis, modals com checklists de 50+ episódios, busca em tempo real e coleções dinâmicas) resultaria em código frágil e propenso a regressões de DOM.
- **Alternativa B (Next.js / Nuxt SSR Full-Stack):** Rejeitada por introduzir um servidor Node.js intermediário redundante, violando o princípio de simplicidade operacional do homelab já coberto pelo FastAPI.
- **Alternativa C (Vite + React + Tailwind compilando para assets estáticos do FastAPI):** Aceita. Combina tipagem estrita via TypeScript, componentes modulares reutilizáveis e produtividade de design com Tailwind, mantendo a execução final em um único comando Python (`python -m uvicorn`).

## 4. Consequências

- **Positivas:** Experiência cinematográfica premium no padrão Netflix; interface de alta performance com carregamento instantâneo; zero atrito para obtenção de torrents e marcação de progresso; compatibilidade total com Smart TVs, TV Boxes, tablets e smartphones.
- **Negativas / Mitigações:** Requer compilação via `npm run build` ao atualizar o frontend. Mitigado através de targets dedicados no `Makefile` (`make build-front` e `make dev-front`).
